# codex-work-kit

Codex로 짧은 업무 과제를 할 때 쓰는 개인 작업 지침과 문서 템플릿이다. 과제 답안이나 코드는 들어 있지 않다.

## 쓰는 법

```bash
git clone --depth 1 https://github.com/<계정>/codex-work-kit /tmp/kit
cp /tmp/kit/AGENTS.md ./AGENTS.md
cp /tmp/kit/templates/PLAN.md /tmp/kit/templates/DECISIONS.md ./
```

- `AGENTS.md`: Codex 작업 원칙
- `templates/PLAN.md`, `templates/DECISIONS.md`: 조건표와 판단 기록 양식
- `prompts.md`: 위임·리뷰 요청문, 업무 담당자 질문 목록, 설명 답변 틀
